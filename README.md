# -AI-Travel-Planner

AI Travel Planner is a Streamlit-based application that helps users plan trips by providing flight details, hotel recommendations, live weather information, and tourist attractions for a selected destination. The system uses JSON datasets for flights, hotels, and places, along with the Open-Meteo API for real-time weather updates.

The project follows an agentic workflow where a travel agent coordinates multiple tools to gather travel information and generate a structured itinerary. Users simply enter a source city and destination city, and the application presents the best available flight, recommended hotel, current weather conditions, and a suggested travel itinerary.

Technologies used include Python, Streamlit, JSON datasets, Open-Meteo API, and LangChain-based tool integration. The project demonstrates modular programming, API integration, agent-based decision making, and interactive web application development.
